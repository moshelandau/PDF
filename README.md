# PDF Editor

A simple desktop PDF editor with the following features:

- **Rotate pages** - Rotate individual or all pages (90°, 180°, 270°)
- **Delete pages** - Remove specific pages from a PDF
- **Auto-rotate** - Automatically detect and fix page orientation
- **Merge PDFs** - Combine multiple PDF files into one
- **Split PDF** - Split by page range or file size

## Installation

```bash
pip install -r requirements.txt
```

## Usage

```bash
python pdf_editor.py
```
